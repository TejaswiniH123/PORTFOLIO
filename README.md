# 📦 Installation

### Clone the repository

```bash
git clone https://github.com/TejaswiniH123/PORTFOLIO.git
```

### Navigate into the project

```bash
cd PORTFOLIO
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
